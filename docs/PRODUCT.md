# Mindough 产品说明

名字来自“满都”（都读 dōu），英文读 /ˈmaɪn.doʊ/。

## 给谁 / 解决什么
给 Rei 自己（登录范围待定）。市面任务工具都靠多层分类管理；Mindough 让任务完成后自然接上后续任务（一个或多个，FS 完成→开始），像前导图 PDM，同时有一条 Agenda 式时间线记琐事。

## 核心概念
- 任务：只有 markdown 正文，没有标题；状态 待办 / 进行中 / 完成 / 关闭（没有“取消”；完成和关闭都算结束，都能解锁后续，但只有完成算成就；都可重新打开）。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS，前置全部结束（完成或关闭）→ 可开始，否则被阻塞；可跨组；不允许成环。
- 组：名称、图标、开始 / 结束时间、分类；装多个任务。
- 分类：名称 + 颜色，挂在组上。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，可设目标时长）、计数（做够一定数量）、倒数日（等到某一天）；可定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面叫法见 docs/COPY.md。
- 打卡分类：重复任务的分类，内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），可改名、隐藏、新增；选择器可搜索；打卡页按分类筛选 / 分组（空分类不显示）。
- 资料库：每种非“普通”的类型都有一个库（影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱；人物就是人物库），自定义类型自动有库。新建任务选好类型后，主输入变成「选一部影视…」：边打字边搜（模糊、最近用到在前、带缩略图），没有就「新建“xxx”」当场填资料。一条资料可以被多件任务用（重看、再去一次）；改资料，用到它的任务一起变。资料库页按库切换，海报 / 方形 / 横幅 / 头像网格，可搜索、添加，点开看相关任务。
- 资料字段 / 任务字段：片名、海报、年份、作者、平台、链接这类属于“这部片本身”，存在资料上；看到第几集、读到第几页、这次买几件属于“这一次”，存在任务上。
- 人物：人物列表，每人有头像；任务可关联人物。人物也是资料库里的一个库。
- 任务类型：决定显示方式和新建模板。默认“普通”：无标题的 markdown 文本；内置 影视、游戏、书籍、项目、课程、旅行、购物、餐厅、饮食、人物；可自定义版式、字段、正文模板；组可设默认类型。

## MVP 功能
0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）
1. 琐事列表（Agenda 式时间线，今天居中）
2. 组视图（卡片 + 组内列表 + 组内依赖图）
3. 依赖图（全局 / 按组，拖线连依赖，颜色区分状态）
4. 可做清单（所有可开始的任务）
5. 完成任务时提示解锁了哪些后续，可一键新建后续
6. 快速新建、搜索、按分类筛选
7. 任务类型：内置 10 种 + 自定义（显示变体 + 创建模板）
8. 打卡：四种完成方式 + 重复 + 连续天数，打卡页用 GitHub 式活动热力图
9. 资料库：每个类型一个库，新建时直接选，没有再新建；⌘K 也能搜到资料并「用它新建任务」
10. macOS / Windows / iOS / Android / Web，离线可用，多端同步（Google 登录）
