# Mindough 产品说明

名字来自“满都”（都读 dōu），英文读 /ˈmaɪn.doʊ/。

## 给谁 / 解决什么
给 Rei 自己（登录范围待定）。市面任务工具都靠多层分类管理；Mindough 让任务完成后自然接上后续任务（一个或多个，FS 完成→开始），像前导图 PDM，同时有一条 Agenda 式时间线记琐事。

## 核心概念
- 任务：只有 markdown 正文，没有标题；状态 待办 / 进行中 / 完成 / 关闭（没有“取消”；完成和关闭都算结束，都能解锁后续，但只有完成算成就；都可重新打开）。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS，前置全部结束（完成或关闭）→ 可开始，否则被阻塞；可跨组；不允许成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」）；不用等、也不会解锁对方。详情里和前后关系放在一起（「关系」），关系图上是没有箭头的点线。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面；计时 / 计数 / 倒数日 / 今天打卡收成顶栏状态旁的小胶囊，点开看完整进度和开始 / 暂停；资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性里的一行，没填时只一行淡字。
- 组：名称、图标、开始 / 结束时间、分类；装多个任务。
- 分类：名称 + 颜色，挂在组上。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，可设目标时长）、计数（做够一定数量）、倒数日（等到某一天）；可定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面叫法见 docs/COPY.md。
- 打卡分类：重复任务的分类，内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），可改名、隐藏、新增；选择器可搜索；打卡页按分类筛选 / 分组（空分类不显示）。
- 资料库：每种非“普通”的类型都有一个库（影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱；人物就是人物库），自定义类型自动有库。新建任务选好类型后，主输入变成「选一部影视…」：边打字边搜（模糊、最近用到在前、带缩略图），没有就「新建“xxx”」当场填资料。一条资料可以被多件任务用（重看、再去一次）；改资料，用到它的任务一起变。资料库页按库切换，海报 / 方形 / 横幅 / 头像网格，可搜索、添加，点开看相关任务。
- 资料合并：同一部片记成了两条（「沙丘2」和「Dune: Part Two」）时可以合成一条：资料详情 ··· 「合并到…」，或资料库页多选后「合并」；资料库页还会提示「可能重复 N 组」（同名，或 IMDb / 豆瓣编号相同），一组一组确认。并排对比，选留下哪条、有冲突的字段各选一个；用到的任务都改用留下的那条，合并后可撤销。人物同样可以合并。
- 资料字段 / 任务字段：片名、海报、年份、作者、平台、链接这类属于“这部片本身”，存在资料上；看到第几集、读到第几页、这次买几件属于“这一次”，存在任务上。
- 人物：人物列表，每人有头像；任务可关联人物。人物也是资料库里的一个库。
- 任务类型：决定显示方式和新建模板。默认“普通”：无标题的 markdown 文本；内置 影视、游戏、书籍、项目、课程、旅行、购物、餐厅、饮食、人物；可自定义版式、字段、正文模板；组可设默认类型。类型编辑器（设置 →「类型」、资料库页「编辑」）：新建类型；改名字、图标（lucide 或 emoji）、颜色、资料库版式（竖版海报 / 方形 / 横幅 / 圆形）、默认完成方式、正文模板、在选择器里的顺序与隐藏；字段增删改名、排序、隐藏，资料字段 / 任务字段；删掉的字段值还留着，加回同名字段又能看到；内置类型只能隐藏，自定义类型没人用时才能删。

## MVP 功能
0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）；待安排：还没定哪天做的事都在这里（新建的任务默认进这里，从我的一天新建的才直接进今天）
1. 琐事列表（Agenda 式时间线，今天居中）
2. 组视图（卡片 + 组内列表 + 组内依赖图）
3. 依赖图（全局 / 按组，拖线连依赖，颜色区分状态；相关任务画成点线）
4. 可做清单（所有可开始的任务）
5. 完成任务时提示解锁了哪些后续，可一键新建后续
6. 快速新建、搜索、按分类筛选
7. 任务类型：内置 10 种 + 自定义（显示变体 + 创建模板）
8. 打卡：四种完成方式 + 重复 + 连续天数，打卡页用 GitHub 式活动热力图
9. 资料库：每个类型一个库，新建时直接选，没有再新建；⌘K 也能搜到资料并「用它新建任务」
10. macOS / Windows / iOS / Android / Web，离线可用，多端同步（Google 登录；改动后自动同步，离线时存在本机、联网后补上；同一件事两边都改，以后改的那次为准；打卡两边都算；退出登录数据还在）
11. 导入导出：设置里把整个库导出成 Markdown 文件夹（zip，Obsidian 能直接打开）；能导回来（按 id 认，已有的跳过或选择覆盖），也能导入任何 Markdown 文件夹（每个 .md 一件任务、文件夹是组）；导入前先预览，导入后可整批撤销（格式见 docs/EXPORT.md）

## 路线图（详见 docs/PLAN.md）
- M3 天天好用：提醒通知、所见即所得的 Markdown 编辑器、小组件（我的一天 / 今天要打卡）、桌面外链走系统浏览器、各平台安装包、界面收尾。
- M4 更聪明：自定义类型编辑器、按名字自动补全资料（TMDB / 豆瓣、Steam、Open Library）、资料合并、Markdown 文件夹导入导出。
- M5 项目视角：SS/FF/SF 与间隔、关键路径与日期推算、甘特图、正文逐字合并。

## 不做
多人协作与共享、多层文件夹分类。
