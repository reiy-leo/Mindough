# Mindough（念头团）产品说明

名字（Rei 2026-10-24 定）：英文「Mindough」，中文「念头团」。中文界面显示念头团，英文界面显示 Mindough；网页标题、主屏幕上的名字、关于、菜单栏都跟着语言走。安装包名、bundle id、PWA manifest 的 name 还是 Mindough。

## 给谁 / 解决什么
给 Rei 自己用（开放给谁登录还没定）。市面上的任务工具都靠多层分类来管；Mindough 让一件任务做完后自然接上下一件（一件或几件，FS：完成→开始），像前导图（PDM）。琐事另外记在一条 Agenda 式的时间线上。

## 核心概念
- 任务：只有 markdown 正文，没有标题。状态有 待办 / 进行中 / 完成 / 关闭，没有“取消”。完成和关闭都算结束，都能解锁后续，但只有完成算成就；两种都能重新打开。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS。前置都结束了（完成或关闭），这件就可开始，否则就是被阻塞；能跨项目；不能绕成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」），不用等对方，也不会解锁对方。详情里它和前后关系放在一起（「关系」）；在项目的关系图视图上，是一条没有箭头的点线。
- 任务链（Rei 2026-10-23：「可以一键展示整个FS的一条线上的所有任务。当前一个任务只能展示它的前后任务，但前任务的前任务是没展示出来的」；同日：「整条线不要弹窗。每个步骤显示相对时间，而不是第几步。改名成‘任务链’」）：一眼看完这件任务前前后后的整条线。
  - 开关：在详情「关系」标题旁边，有先做完这些或做完后解锁时才出现。打开后不弹窗，就在「关系」里把「先做完这些 / 做完后解锁」换成整条任务链，关掉就恢复；「相关任务」照常在下面。开关只记在这台设备上，换一件任务也沿用。
  - 列什么：顺着前后关系，把这件任务所有的上游（前置的前置……）和下游（后续的后续……）都列出来，从最上游排到最下游，步和步之间是竖线加箭头。只算前后关系：相关任务、上游分出去的无关兄弟任务、删掉的任务和关系都不算。
  - 每一步写时间，不写第几步：都结束了，写什么时候完成的（「今天完成」「昨天完成」「3 天前完成」）；没结束，写最早的计划日期离今天多久（「今天」「明天」「5 天后」「已过 2 天」，过期是红色）；超过 30 天写日期；都没日期写「未定时间」。
  - 一步有几件（分叉、汇合）时纵向叠着，往里缩一点（详情栏窄，桌面和手机都这样）。每件显示状态（已完成 / 已关闭 / 进行中 / 还不能开始 / 可开始），当前这件高亮并标「这件」；接的不正好是上一步的全部时，写「接在「X」后面」。
  - 顶上是「已完成 N / 共 M」和进度条。点一件，打开它的详情。
- 任务详情不弹窗，三列布局（Rei 2026-10-23：「任务链不要再弹窗了，任务详情如果不弹窗最好了，最好做成三列布局」）。
  - 宽屏：侧边栏 | 当前视图的任务列表 | 任务详情，像 Things 3、提醒事项、邮件那样。点列表里的一件，右边显示它的详情，列表里那行高亮；没选中时，右边写「选一件任务查看详情」。日记、资料库、设置这类没有任务列表的页面，打开任务时才出现右边这一栏。
  - 右边这一栏能拖宽拖窄（这台设备会记住）；按 Esc 或点右上角关闭就取消选中，↑ ↓ 换一件。从 ⌘K、资料库、通知、链接打开的任务，也显示在右边。
  - 窗口窄一些（平板、小窗口）时，侧边栏收成一列图标，只剩列表和详情两栏；没选中时列表铺满。
  - 手机上详情整页推进来；点左上「返回」、从左边缘右滑、按系统返回键，都回到列表。
  - 选中的是哪件写在地址里，刷新后还在。新建任务还是右下角加号的面板；桌面置顶小窗里的详情还是弹窗。
  - 三种皮肤各有样子：Apple 像提醒事项的检查器，WinUI 像邮件的阅读窗格，Material 3 是 list-detail 布局。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面。计时、计数、倒数日、今天打卡收成顶栏状态旁的小胶囊，点开看完整进度，也能开始、暂停。资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性卡片里的一行，没填时只有一行淡字。其余单值属性（类型、完成方式、日期、重复、打卡分类、提醒、项目、和谁有关）排成一行胶囊（Rei 2026-10-25 选方案 A · 胶囊行）：只显示设过的，默认的（普通、勾选完成、只做一次、没日期、不提醒、不放进项目、没有人）不显示。每个胶囊是图标加值，放不下就换行，顺序固定。点胶囊打开原来的选择器。电脑上悬停会出现小 ×，点一下恢复默认，可以撤销；手机上在选择器里选「无」那一项。行尾的「+」列出还没设的属性，选一项直接打开它的选择器；全都设了就没有「+」。一个都没设时只有「+ 添加属性」。键盘上 Tab 到胶囊，Enter 打开，Backspace 或 Delete 清除。「关闭」（重复任务叫「不再打卡」）在顶栏「…」菜单里，不在底部（Rei 2026-10-17：「任务窗口底部的close按钮，移动到ellipsis下拉菜单中去」）。菜单分三组，用分隔线隔开：我的一天 ｜ 直接标为完成 · 关闭（结束了的换成「重新打开」/「恢复打卡」） ｜ 删除…。底部只留主操作（完成 / 计时 / +1 / 打卡）；结束了的任务，底部还是「这件事已关闭…」+「重新打开」。
- 项目：有名称、图标、开始 / 结束时间、分类，里面放多件任务。
- 分类：名称加颜色，挂在项目上。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，能设目标时长）、计数（做够一定数量）、倒数日（等到某一天）。还能定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面上的叫法见 docs/COPY.md。
- 打卡分类：重复任务的分类，内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），能改名、隐藏、新增；选择器里能搜；打卡页按分类筛选、分组（空的分类不显示）。
- 资料库：除了“普通”，每种类型都有一个库（影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱；人物就是人物库），自定义类型也自动有库。
  - 新建任务选好类型后，主输入框变成「选一部影视…」：边打字边搜（模糊匹配，最近用过的在前，带缩略图）；没有就点「新建“xxx”」，当场填资料。
  - 一条资料可以给多件任务用（重看一遍、再去一次）；改了资料，用到它的任务一起变。
  - 资料库页按库切换，显示成海报 / 方形 / 横幅 / 头像网格，能搜、能添加，点开看相关任务。
- 资料合并：同一部片记成了两条（「沙丘2」和「Dune: Part Two」）时，可以合成一条：在资料详情 ··· 里选「合并到…」，或者在资料库页多选后点「合并」。资料库页还会提示「可能重复 N 组」（同名，或 IMDb / 豆瓣编号相同），一组一组确认。合并时并排对比，选留下哪条，有冲突的字段各选一个；用到它们的任务都改用留下的那条，合并后能撤销。人物也能这样合并。
- 资料字段 / 任务字段：片名、海报、年份、作者、平台、链接这类属于“这部片本身”，存在资料上；看到第几集、读到第几页、这次买几件属于“这一次”，存在任务上。
- 人物：一个人物列表，每人有头像；任务能关联人物。人物也是资料库里的一个库。
- 任务类型：决定任务怎么显示、新建时带什么模板。
  - 默认是“普通”：没有标题的 markdown 文本。内置的还有 影视、游戏、书籍、项目、课程、旅行、购物、餐厅、饮食、人物；也能自定义版式、字段、正文模板。项目可以设默认类型。
  - 类型编辑器（设置 →「类型」，或资料库页「编辑」）：能新建类型；能改名字、图标（lucide 或 emoji）、颜色、资料库版式（竖版海报 / 方形 / 横幅 / 圆形）、默认完成方式、正文模板、在选择器里的顺序；字段能增删、改名、排序、隐藏，分资料字段和任务字段。删掉的字段，值还留着，加回同名字段又能看到。
  - 类型建好后只能改和归档，不能删，内置的和自定义的都一样（Rei 2026-10-17）。归档只是让以后的任务选不到它：它不再出现在选择器（新建 / 改类型 / 项目默认类型）、资料库标签条和类型编辑器主列表里（编辑器列表最底下「已归档 N 个」里能取消归档）。用过它的旧任务和资料照常显示，字段值也能改；⌘K 照样搜得到它的资料；以它为默认类型的项目，照样用它新建任务，项目页照常显示（Rei 2026-10-17 纠正：「项目的类型被归档后不退回，搜索里出它的资料。归档只是让它不能被后续任务使用呀」）。

## MVP 功能
0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）。「建议」行尾不放原因徽章（今天到期…），也不放「+ 加入」按钮（Rei 2026-10-25「任何情况下都不显示这两个按钮」）：到期看行里的日期，加入用这一行的右键 / 长按菜单（所有任务列表行都有：查看详情 ｜ 加入 / 移出我的一天）。待安排：还没定哪天做的事都在这里；新建的任务默认进这里，从我的一天新建的才直接进今天
1. 琐事列表（Agenda 式时间线，今天居中）
2. 项目视图（卡片 + 项目内列表 + 项目内依赖图）
3. 依赖图（项目里的「关系图」视图，拖线连依赖，颜色区分状态；相关任务画成点线）。侧边栏的全局「关系图」页 2026-10-23 删掉了（Rei：「侧边栏的Graph选项卡并不是我想要的，可以删掉」）；想看一件任务前前后后的整条链，用详情里的「任务链」
4. 可做清单（所有可开始的任务）
5. 完成任务时提示解锁了哪些后续，一键就能新建后续
6. 快速新建、搜索、按分类筛选
7. 任务类型：内置 10 种 + 自定义（显示变体 + 创建模板）
8. 打卡：四种完成方式 + 重复 + 连续天数，打卡页用 GitHub 式活动热力图。每张打卡卡片里不再挤一张小图：卡片左上角有个小圆点，点一下在卡片下面展开整行宽的活动图（格子多少随宽度变，最近一天在最右），再点收起；默认收起，展开了哪几张只记在这台设备上（Rei 2026-10-25）
9. 资料库：每个类型一个库，新建时直接选，没有再新建；⌘K 也能搜到资料并「用它新建任务」；影视 / 书 / 游戏还能在线找（TMDB / 豆瓣、Open Library、Steam），选中就填好片名、年份、IMDb、海报等，编辑资料里可以「自动补全」，资料上写明来源。书的封面不从任何平台取，只能自己上传或粘贴（Rei 2026-10-17）。书填了或粘贴了 ISBN，就按 ISBN 取那一版的信息（出版社、出版年份、页数、ISBN）；按书名找，只补作者、首版年份、页数。资料图（影视 / 游戏的在线图、自己上传的图、人物头像）先按版式统一宽高再存：竖版海报 600×900、方形 / 圆形 600×600、横幅 1280×720，居中裁切，存 WebP；任务里的普通图片不裁，只把长边缩到 1600 以内
10. macOS / Windows / iOS / Android / Web，离线可用，多端同步（Google 登录；改动后自动同步，离线时存在本机、联网后补上；同一件事两边都改，以后改的那次为准；打卡两边都算；退出登录数据还在；设置 → 账户写清楚数据怎么走：先存本机 → Worker 核对是你本人 → 存进云端库（Turso 东京，或 Cloudflare D1，由服务器设置决定，Rei 2026-10-17）→ 其他设备从那里同步，图片在 Cloudflare R2）
11. 导入导出：设置里把整个库导出成 Markdown 文件夹（zip，Obsidian 能直接打开）；能导回来（按 id 认，已有的跳过或选择覆盖），也能导入普通的 Markdown 文件夹（每个 .md 是一件任务，文件夹是项目）。导入前先预览，导入后能整批撤销（格式见 docs/EXPORT.md）
12. 正文与备注里的网络图片不显示（Rei 2026-10-17：「编辑器的网络插图」「编辑器不渲染网络图片」）：markdown 里的 `![说明](https://…)` 照原样保存，编辑器和只读显示里都只显示成一段链接色的文字（有说明写说明，没有写网址，悬停看完整地址），不去网上拉图；自己上传 / 导入进来的图（存在 Mindough 里的）照常显示。资料 / 任务字段里的图片框不受影响（还能粘贴图片链接）
13. 内容和备注所见即所得：直接打 markdown 就排好（标题、粗斜删、代码、引用、列表、清单、分隔线、`[文字](网址)`、`<网址>`、裸网址、`|a|b|` 回车成表格）；Tab 在列表里缩进、焦点不跑。链接点一下就打开（Rei 2026-10-17：「放上去就展示吧，点一下是访问链接」）；鼠标移上去（触屏长按选中）出小浮层看原地址、「编辑」「去掉链接」，⌘K 在链接里也是改它。编辑链接（Rei 2026-10-17：「编辑器中链接要支持编辑名称和链接」）文字和网址一起改：桌面上浮层原地展开成「文字」「链接」两栏，手机上从底部弹出（避开键盘）；加新链接（工具栏链接按钮、⌘K）也是这个框，选了字就预填成文字；文字空着用网址当名字，网址不用写 https://，写错了框里会提示；回车保存、Esc 取消
14. GitHub 扩展语法（Rei 2026-10-17）：引用块第一行写 `[!NOTE]` `[!TIP]` `[!IMPORTANT]` `[!WARNING]` `[!CAUTION]`（大小写都行）显示成带图标和颜色的提示块（注意 / 提示 / 重要 / 警告 / 小心）；`$公式$`、`$$公式$$` 显示成数学公式（KaTeX，离线可用），点一下改源码；「$5 和 $10」这种价格不当公式（同 GitHub 的规则）；脚注 `[^1]`、表格对齐也显示。手打 `> [!NOTE]`、`$x$` 当场就变；存的 markdown 原样不变，拿到 GitHub、Obsidian 也是同样的意思
15. 折叠块（Rei 2026-10-17）：`<details><summary>标题</summary>内容</details>` 在编辑器里也是能折叠的一块——左边小三角点一下展开 / 收起，标题和正文都能直接改，正文里可以放列表、清单、提示块、公式，甚至再套折叠块。加一个：工具栏「折叠块」（光标所在那段变成标题；选了几段就把它们收进去；在折叠块标题里再点一下拆开），或者手打一行 `<details>` 回车。标题里回车进正文，正文空行再回车出来；标题开头退格拆开。展开 / 收起只是看，不算改了内容；原文写了 `open` 的打开时默认展开。存的还是那段 HTML，GitHub、Obsidian 照样能折叠
16. 编辑时块与块之间的距离和只读显示一样紧凑（Rei 2026-10-17）：段落、列表、标题、引用、提示块、公式、表格、折叠块之间不再多出一截空白
17. 外壳（Rei 2026-10-17：「macOS的边栏框要贯通，titlebar不展示」「去掉全局右键菜单，不允许页面左右移动，侧边栏不要添加软件title，新建任务移动到右下角浮动」）：macOS 桌面 app 没有系统标题栏，红绿灯浮在侧边栏左上角，侧边栏从窗口顶一直到底，顶部空白处拖得动窗口、双击放大（小窗保留标题栏）；侧边栏不放「Mindough」名字和图标；新建任务是右下角的浮动加号按钮（三种皮肤各自的样子，快捷键 N 不变）；页面不会左右晃动；不弹浏览器自带的右键菜单（输入框和编辑器里照常能复制粘贴）。
18. 日记（Rei 2026-10-17，英文 Journal）：一天一篇，侧边栏「今天」小节、手机「更多」、我的一天底部「今天的日记」小卡都能进；日记页左边月历 + 这个月的列表，右边那天的日记：心情（12 个带动画的图标：开心、兴奋、感恩、满足、平静、一般、无聊、疲惫、焦虑、难过、烦躁、生气，可以不填）+ 和任务一样的编辑器。设置里「一天从几点开始」（默认 5 点，凌晨 3 点写的算前一天，只用于日记）、「每天提醒写日记」（默认开、晚上 9 点，写没写都响）。将来的日子不能写。「这一天」汇总不放进日记。两台设备同时改了同一天，后改的为准，另一版收在日记末尾的折叠块里，不丢字。⌘K 能搜到日记、有「写今天的日记」；导出到 `journal/年/月/日期.md`；深链接 `mindough://journal/today`
