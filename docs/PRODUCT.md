# Mindough 产品说明

名字来自“满都”（都读 dōu），英文读 /ˈmaɪn.doʊ/。

## 给谁 / 解决什么
给 Rei 自己（登录范围待定）。市面任务工具都靠多层分类管理；Mindough 让任务完成后自然接上后续任务（一个或多个，FS 完成→开始），像前导图 PDM，同时有一条 Agenda 式时间线记琐事。

## 核心概念
- 任务：只有 markdown 正文，没有标题；状态 待办 / 进行中 / 完成 / 关闭（没有“取消”；完成和关闭都算结束，都能解锁后续，但只有完成算成就；都可重新打开）。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS，前置全部结束（完成或关闭）→ 可开始，否则被阻塞；可跨组；不允许成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」）；不用等、也不会解锁对方。详情里和前后关系放在一起（「关系」），关系图上是没有箭头的点线。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面；计时 / 计数 / 倒数日 / 今天打卡收成顶栏状态旁的小胶囊，点开看完整进度和开始 / 暂停；资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性里的一行，没填时只一行淡字。「关闭」（重复任务叫「不再打卡」）在顶栏「…」菜单里，不在底部（Rei 2026-10-17：「任务窗口底部的close按钮，移动到ellipsis下拉菜单中去」）；菜单是 我的一天 ｜ 直接标为完成 · 关闭（结束了的换成「重新打开」/「恢复打卡」） ｜ 删除…，组之间有分隔线；底部只留主操作（完成 / 计时 / +1 / 打卡），结束了的任务底部仍是「这件事已关闭…」+「重新打开」。
- 组：名称、图标、开始 / 结束时间、分类；装多个任务。
- 分类：名称 + 颜色，挂在组上。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，可设目标时长）、计数（做够一定数量）、倒数日（等到某一天）；可定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面叫法见 docs/COPY.md。
- 打卡分类：重复任务的分类，内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），可改名、隐藏、新增；选择器可搜索；打卡页按分类筛选 / 分组（空分类不显示）。
- 资料库：每种非“普通”的类型都有一个库（影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱；人物就是人物库），自定义类型自动有库。新建任务选好类型后，主输入变成「选一部影视…」：边打字边搜（模糊、最近用到在前、带缩略图），没有就「新建“xxx”」当场填资料。一条资料可以被多件任务用（重看、再去一次）；改资料，用到它的任务一起变。资料库页按库切换，海报 / 方形 / 横幅 / 头像网格，可搜索、添加，点开看相关任务。
- 资料合并：同一部片记成了两条（「沙丘2」和「Dune: Part Two」）时可以合成一条：资料详情 ··· 「合并到…」，或资料库页多选后「合并」；资料库页还会提示「可能重复 N 组」（同名，或 IMDb / 豆瓣编号相同），一组一组确认。并排对比，选留下哪条、有冲突的字段各选一个；用到的任务都改用留下的那条，合并后可撤销。人物同样可以合并。
- 资料字段 / 任务字段：片名、海报、年份、作者、平台、链接这类属于“这部片本身”，存在资料上；看到第几集、读到第几页、这次买几件属于“这一次”，存在任务上。
- 人物：人物列表，每人有头像；任务可关联人物。人物也是资料库里的一个库。
- 任务类型：决定显示方式和新建模板。默认“普通”：无标题的 markdown 文本；内置 影视、游戏、书籍、项目、课程、旅行、购物、餐厅、饮食、人物；可自定义版式、字段、正文模板；组可设默认类型。类型编辑器（设置 →「类型」、资料库页「编辑」）：新建类型；改名字、图标（lucide 或 emoji）、颜色、资料库版式（竖版海报 / 方形 / 横幅 / 圆形）、默认完成方式、正文模板、在选择器里的顺序；字段增删改名、排序、隐藏，资料字段 / 任务字段；删掉的字段值还留着，加回同名字段又能看到。类型创建后只能修改和归档，不支持删除（内置、自定义一样，Rei 2026-10-17）：归档只是让它不能被后续任务选用：不再出现在选择器（新建 / 改类型 / 组默认类型）、资料库标签条和类型编辑器主列表里（编辑器列表最底下「已归档 N 个」可取消归档）；引用它的旧任务和资料照常显示、能改字段值，⌘K 照常搜得到它的资料，以它为默认类型的组照样用它新建任务、组页照常显示（Rei 2026-10-17 纠正：「组的类型被归档后不退回，搜索里出它的资料。归档只是让它不能被后续任务使用呀」）。

## MVP 功能
0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）；待安排：还没定哪天做的事都在这里（新建的任务默认进这里，从我的一天新建的才直接进今天）
1. 琐事列表（Agenda 式时间线，今天居中）
2. 组视图（卡片 + 组内列表 + 组内依赖图）
3. 依赖图（全局 / 按组，拖线连依赖，颜色区分状态；相关任务画成点线）
4. 可做清单（所有可开始的任务）
5. 完成任务时提示解锁了哪些后续，可一键新建后续
6. 快速新建、搜索、按分类筛选
7. 任务类型：内置 10 种 + 自定义（显示变体 + 创建模板）
8. 打卡：四种完成方式 + 重复 + 连续天数，打卡页用 GitHub 式活动热力图
9. 资料库：每个类型一个库，新建时直接选，没有再新建；⌘K 也能搜到资料并「用它新建任务」；影视 / 书 / 游戏还能在线找（TMDB / 豆瓣、Open Library、Steam），选中就填好片名、年份、IMDb、海报等，编辑资料里可以「自动补全」，资料上写明来源。书的封面不从任何平台取，只能自己上传 / 粘贴（Rei 2026-10-17）；书填或粘贴 ISBN 就按 ISBN 取那一版（出版社、出版年份、页数、ISBN），按书名只补作者、首版年份、页数。资料图（影视 / 游戏的在线图、自己上传、人物头像）先按版式统一宽高再存：竖版海报 600×900、方形 / 圆形 600×600、横幅 1280×720，居中裁切，存 WebP；任务里的普通图片不裁，只把长边缩到 1600 以内
10. macOS / Windows / iOS / Android / Web，离线可用，多端同步（Google 登录；改动后自动同步，离线时存在本机、联网后补上；同一件事两边都改，以后改的那次为准；打卡两边都算；退出登录数据还在；设置 → 账户写清楚数据怎么走：先存本机 → Worker 核对是你本人 → 存进云端库（Turso 东京，或 Cloudflare D1，由服务器设置决定，Rei 2026-10-17）→ 其他设备从那里同步，图片在 Cloudflare R2）
11. 导入导出：设置里把整个库导出成 Markdown 文件夹（zip，Obsidian 能直接打开）；能导回来（按 id 认，已有的跳过或选择覆盖），也能导入任何 Markdown 文件夹（每个 .md 一件任务、文件夹是组）；导入前先预览，导入后可整批撤销（格式见 docs/EXPORT.md）
12. 正文与备注里的网络图片不显示（Rei 2026-10-17：「编辑器的网络插图」「编辑器不渲染网络图片」）：markdown 里的 `![说明](https://…)` 照原样保存，编辑器和只读显示里都只显示成一段链接色的文字（有说明写说明，没有写网址，悬停看完整地址），不去网上拉图；自己上传 / 导入进来的图（存在 Mindough 里的）照常显示。资料 / 任务字段里的图片框不受影响（还能粘贴图片链接）
13. 内容和备注所见即所得：直接打 markdown 就排好（标题、粗斜删、代码、引用、列表、清单、分隔线、`[文字](网址)`、`<网址>`、裸网址、`|a|b|` 回车成表格）；Tab 在列表里缩进、焦点不跑。链接点一下就打开（Rei 2026-10-17：「放上去就展示吧，点一下是访问链接」）；鼠标移上去（触屏长按选中）出小浮层看原地址、「编辑」「去掉链接」，⌘K 在链接里也是改它。编辑链接（Rei 2026-10-17：「编辑器中链接要支持编辑名称和链接」）文字和网址一起改：桌面上浮层原地展开成「文字」「链接」两栏，手机上从底部弹出（避开键盘）；加新链接（工具栏链接按钮、⌘K）也是这个框，选了字就预填成文字；文字空着用网址当名字，网址不用写 https://，写错了框里会提示；回车保存、Esc 取消
14. GitHub 扩展语法（Rei 2026-10-17）：引用块第一行写 `[!NOTE]` `[!TIP]` `[!IMPORTANT]` `[!WARNING]` `[!CAUTION]`（大小写都行）显示成带图标和颜色的提示块（注意 / 提示 / 重要 / 警告 / 小心）；`$公式$`、`$$公式$$` 显示成数学公式（KaTeX，离线可用），点一下改源码；「$5 和 $10」这种价格不当公式（同 GitHub 的规则）；脚注 `[^1]`、表格对齐也显示。手打 `> [!NOTE]`、`$x$` 当场就变；存的 markdown 原样不变，拿到 GitHub、Obsidian 也是同样的意思
15. 折叠块（Rei 2026-10-17）：`<details><summary>标题</summary>内容</details>` 在编辑器里也是能折叠的一块——左边小三角点一下展开 / 收起，标题和正文都能直接改，正文里可以放列表、清单、提示块、公式，甚至再套折叠块。加一个：工具栏「折叠块」（光标所在那段变成标题；选了几段就把它们收进去；在折叠块标题里再点一下拆开），或者手打一行 `<details>` 回车。标题里回车进正文，正文空行再回车出来；标题开头退格拆开。展开 / 收起只是看，不算改了内容；原文写了 `open` 的打开时默认展开。存的还是那段 HTML，GitHub、Obsidian 照样能折叠
16. 编辑时块与块之间的距离和只读显示一样紧凑（Rei 2026-10-17）：段落、列表、标题、引用、提示块、公式、表格、折叠块之间不再多出一截空白
17. 外壳（Rei 2026-10-17：「macOS的边栏框要贯通，titlebar不展示」「去掉全局右键菜单，不允许页面左右移动，侧边栏不要添加软件title，新建任务移动到右下角浮动」）：macOS 桌面 app 没有系统标题栏，红绿灯浮在侧边栏左上角，侧边栏从窗口顶一直到底，顶部空白处拖得动窗口、双击放大（小窗保留标题栏）；侧边栏不放「Mindough」名字和图标；新建任务是右下角的浮动加号按钮（三种皮肤各自的样子，快捷键 N 不变）；页面不会左右晃动；不弹浏览器自带的右键菜单（输入框和编辑器里照常能复制粘贴）。
18. 日记（Rei 2026-10-17，英文 Journal）：一天一篇，侧边栏「今天」小节、手机「更多」、我的一天底部「今天的日记」小卡都能进；日记页左边月历 + 这个月的列表，右边那天的日记：心情（12 个带动画的图标：开心、兴奋、感恩、满足、平静、一般、无聊、疲惫、焦虑、难过、烦躁、生气，可以不填）+ 和任务一样的编辑器。设置里「一天从几点开始」（默认 5 点，凌晨 3 点写的算前一天，只用于日记）、「每天提醒写日记」（默认开、晚上 9 点，写没写都响）。将来的日子不能写。「这一天」汇总不放进日记。两台设备同时改了同一天，后改的为准，另一版收在日记末尾的折叠块里，不丢字。⌘K 能搜到日记、有「写今天的日记」；导出到 `journal/年/月/日期.md`；深链接 `mindough://journal/today`
19. 附件（Rei 2026-10-17）：任务详情和日记的正文下面一块「附件」。把文件拖上去（出现「松手添加附件」的虚线框），或点「添加附件」选文件，可以一次选多个；手机上能从相册选。原文件原样存（不压缩、不改尺寸），每个不超过 50 MB。图片是方形小图，点开全屏看（关闭、下载，多张左右切换，Esc 或点外面关闭）；其他文件按类型显示图标（PDF、文档、表格、演示、压缩包、音频、视频、代码 / 文本、其他）+ 文件名 + 大小，点一下下载，下载下来还是原来的文件名。上传时看得到进度，能取消，失败能重试；离线或没登录时先存在本机排着，联网后自动传。每个附件能改名、删除（可撤销）。导出时附件放进 zip 的 `attachments/`，能导回来

## 路线图（详见 docs/PLAN.md）
- M3 天天好用：提醒通知、所见即所得的 Markdown 编辑器、小组件（我的一天 / 今天要打卡）、桌面外链走系统浏览器、各平台安装包、界面收尾。
- M4 更聪明：自定义类型编辑器、按名字自动补全资料（TMDB / 豆瓣、Steam、Open Library）、资料合并、Markdown 文件夹导入导出。
- M5 项目视角：SS/FF/SF 与间隔、关键路径与日期推算、甘特图、正文逐字合并。

## 不做
多人协作与共享、多层文件夹分类。
