# Mindough（念头团）产品说明

名字（Rei 2026-10-24 定）：英文「Mindough」，中文「念头团」。中文界面显示念头团，英文界面显示 Mindough；网页标题、主屏幕上的名字、关于、菜单栏都跟着语言走。安装包名、bundle id、PWA manifest 的 name 还是 Mindough。

语言（Rei 2026-10-25「支持西、葡、俄、日、德、法、印尼」）：界面有中文、英文、西班牙语、巴西葡萄牙语、俄语、日语、德语、法语、印尼语九种。设置里选，或者跟随系统（系统语言不在这九种里就用英文）。日期、数字、币种、一周从哪天开始都跟着语言；农历只在中文界面出现；在线查资料时，中文界面按中文查，其他语言都按英文查。

## 给谁 / 解决什么
给 Rei 自己用（开放给谁登录还没定）。市面上的任务工具都靠多层分类来管；Mindough 让一件任务做完后自然接上下一件（一件或几件，FS：完成→开始），像前导图（PDM）。琐事另外记在一条 Agenda 式的时间线上。

## 核心概念
- 任务：只有 markdown 正文，没有标题。状态有 待办 / 进行中 / 完成 / 关闭，没有“取消”。完成和关闭都算结束，都能解锁后续，但只有完成算成就；两种都能重新打开。
- 依赖（界面叫「前后关系」：先做完这些 / 做完后解锁）：FS。前置都结束了（完成或关闭），这件就可开始，否则就是被阻塞；能跨项目；不能绕成环。
- 相关任务：两件事只是有关系、不分先后（比如「新家网络开通」和「退掉旧宽带」），不用等对方，也不会解锁对方。详情里它和前后关系放在一起（「关系」）。
- 任务链（Rei 2026-10-23：「可以一键展示整个FS的一条线上的所有任务。当前一个任务只能展示它的前后任务，但前任务的前任务是没展示出来的」；同日：「整条线不要弹窗。每个步骤显示相对时间，而不是第几步。改名成‘任务链’」）：一眼看完这件任务前前后后的整条线。
  - 开关：在详情「关系」标题旁边，有先做完这些或做完后解锁时才出现。打开后不弹窗，就在「关系」里把「先做完这些 / 做完后解锁」换成整条任务链，关掉就恢复；「相关任务」照常在下面。开关只记在这台设备上，换一件任务也沿用。
  - 列什么：顺着前后关系，把这件任务所有的上游（前置的前置……）和下游（后续的后续……）都列出来，从最上游排到最下游，步和步之间是竖线加箭头。只算前后关系：相关任务、上游分出去的无关兄弟任务、删掉的任务和关系都不算。
  - 每一步写时间，不写第几步：都结束了，写什么时候完成的（「今天完成」「昨天完成」「3 天前完成」）；没结束，写最早的计划日期离今天多久（「今天」「明天」「5 天后」「已过 2 天」，过期是红色）；超过 30 天写日期；都没日期写「未定时间」。
  - 一步有几件（分叉、汇合）时纵向叠着，往里缩一点（详情栏窄，桌面和手机都这样）。每件显示状态（已完成 / 已关闭 / 进行中 / 还不能开始 / 可开始），当前这件高亮并标「这件」；接的不正好是上一步的全部时，写「接在「X」后面」。
  - 顶上是「已完成 N / 共 M」和进度条。点一件，打开它的详情。
- 任务详情不弹窗，三列布局（Rei 2026-10-23：「任务链不要再弹窗了，任务详情如果不弹窗最好了，最好做成三列布局」）。
  - 宽屏：侧边栏 | 当前视图的任务列表 | 任务详情，像 Things 3、提醒事项、邮件那样。点列表里的一件，右边显示它的详情，列表里那行高亮；没选中时，右边写「选一件任务查看详情」。日记、资料库、设置这类没有任务列表的页面，打开任务时才出现右边这一栏。
  - 右边这一栏能拖宽拖窄（这台设备会记住）；按 Esc 或点右上角关闭就取消选中，↑ ↓ 换一件。从 ⌘K、资料库、通知、链接打开的任务，也显示在右边。
  - 窗口窄一些（平板、小窗口）时，侧边栏收成一列图标，只剩列表和详情两栏；没选中时列表铺满。
  - 手机上详情整页推进来；点左上「返回」、从左边缘右滑、按系统返回键，都回到列表。
  - 选中的是哪件写在地址里，刷新后还在。新建任务还是右下角加号的面板；桌面置顶小窗里的详情还是弹窗。
  - 三种皮肤各有样子：Apple 像提醒事项的检查器，WinUI 像邮件的阅读窗格，Material 3 是 list-detail 布局。
- 任务详情布局（Rei 2026-10-16 选方案 A）：标题和正文在最上面。计时、计数、倒数日、今天打卡收成顶栏状态旁的小胶囊，点开看完整进度，也能开始、暂停。资料（游戏、影视…）和任务字段（进度 %、看到哪…）都是属性卡片里的一行，没填时只有一行淡字。其余属性（类型、完成方式、日期、重复、提醒、项目）排成一行胶囊（Rei 2026-10-25 选方案 A · 胶囊行）：只显示设过的，默认的（没有类型、勾选完成、只做一次、没日期、不提醒、不放进项目）不显示。资料（含人物）不进胶囊，挂了就在胶囊下面按库分组列出来，见下面「资料库」（2026-10-28 起，原来的「资料库」「和谁有关」两个胶囊并进了资料）。每个胶囊是图标加值，放不下就换行，顺序固定。点胶囊打开原来的选择器。电脑上悬停会出现小 ×，点一下恢复默认，可以撤销；手机上在选择器里选「无」那一项。行尾的「+」列出还没设的属性，选一项直接打开它的选择器；最后一项是「附件」，点了选文件（可以多选），加过附件它也还在（Rei 2026-10-25）。属性全设了、又不能加附件时才没有「+」。一个都没设时只有「+ 添加属性」。键盘上 Tab 到胶囊，Enter 打开，Backspace 或 Delete 清除。「关闭」（重复任务叫「不再打卡」）在顶栏「…」菜单里，不在底部（Rei 2026-10-17：「任务窗口底部的close按钮，移动到ellipsis下拉菜单中去」）。菜单分三组，用分隔线隔开：我的一天 ｜ 直接标为完成 · 关闭（结束了的换成「重新打开」/「恢复打卡」） ｜ 删除…。底部只留主操作（完成 / 计时 / 计数的快捷按钮 / 打卡）；结束了的任务，底部还是「这件事已关闭…」+「重新打开」。
- 项目：有名称、图标、开始 / 结束时间、类型，里面放多件任务。
- 完成方式（新建时就选）：勾选完成（做完就打勾）、计时（做够一段时间，能设目标时长）、计数（做够一定数量；能设每次加多少和最多三个快捷按钮，比如喝 2000 mL 水点「+250」「+500」，点数字可以直接输总数或「+330」，加错了能撤销上一次，Rei 2026-10-26）、倒数日（等到某一天）。还能定期打卡（每天 / 每周几 / 每月几号 / 每隔几天），记连续次数。界面上的叫法见 docs/COPY.md。
- 类型（Rei 2026-10-26 把打卡分类和项目分类合成一套）：名称、颜色、图标，任务（任何任务）能挂好几个（Rei 2026-10-28，docs/MULTI-TYPE.md），项目挂一个。内置 27 个（记录、整理、游戏、玩乐、健康、运动、护肤、清洁、学习、读书、饮食、作息、冥想、服药、理财、工作、写作、语言、乐器、创作、社交、宠物、植物、采购、个人护理、维护、观影），能加、改名、换颜色和图标、设成不显示，不能删（不显示的选择器里没有，挂着的照常显示）。只在侧栏「管理 → 类型」页里改，设置里没有类型（Rei 2026-10-28「去掉设置中的入口」）。类型页按方案 C 做（Rei 2026-10-28「按方案C执行」，docs/CATEGORY-EDITOR.md）：顶上一个搜索框，打开就能打字，名字、英文名、拼音首字母（「yd」→ 运动）都能搜，↑↓ 选、回车打开，没有同名的就多一行「新建“xxx”」；不搜时按大类分组：身体、生活、学习和工作、爱好、人，自己加的进「其他」，组能折叠，「不显示」的沉到最底下一组、名字变灰；每行只有彩色图标块、名字、用了几次。宽屏左右两栏，右边是选中类型的详情：图标块（点开换颜色、搜图标）、直接改的名字、常用 / 普通 / 不显示三档、换大类，下面是挂了它的任务和项目；窄屏点一行整页推进详情。手机上左滑一行出「常用」「不显示」；电脑上 ⌘1 / ⌘2 / ⌘3 切三档，⌘F 或直接打字去搜索。改动马上保存，改档、换组都能撤销。顺序不用手排（Rei 2026-10-28 定「用「常用 + 最近用过」代替手动排序」）：选择器里标成常用的在前，其余按最近用过的先后排，没用过的按大类排；第一屏放常用的（不足 6 个用最近用过的补齐）+「更多」，「更多」里能搜，底部「管理类型…」去类型页。打卡、倒数日、项目页按类型筛选、分组，只列用到的。
- 资料库：内置的库有影视库、书库、游戏库、项目库、课程库、目的地、好物清单、餐厅库、菜谱，人物就是人物库；也能自己建库。
  - 类型和资料库平级、互不连接（Rei 2026-10-28：「类型是类型，资料库是资料库，是平级的」，docs/MULTI-TYPE.md）。一件任务能挂好几条资料，可以来自不同的库，比如几个人加一部电影；挑资料不改类型，换类型也不动资料。
  - 详情、新建面板里的「资料」：按库分组列出挂着的资料，每个库下面接它的任务字段（人物库不显示任务字段）；「添加资料」打开挑资料的面板，顶上一排库按钮（全部、影视……人物，多了折行），「全部」跨库搜库里已有的，选了库就能模糊搜、在线找、新建「xxx」。点一条挂上，再点去掉，面板不收起。行尾 × 只解开关联。
  - 代码和数据里库还叫 type（`task.type_id` 现在是第一条资料所在的库），界面上叫资料库（Rei 2026-10-26 改的叫法）。
  - 一条资料可以给多件任务用（重看一遍、再去一次）；改了资料，用到它的任务一起变。
  - 资料库页按库切换，显示成海报 / 方形 / 横幅 / 头像网格，能搜、能添加，点开看相关任务。
  - 侧栏（Rei 2026-10-26）：「管理」一节是 资料库、类型，没有单独的「人物」，人物从资料库页的「人物」标签进。任何一个库都能「在侧边栏显示」，显示的库排在「资料库」下面，点了直接进那个库，顺序跟资料库一样，默认都不显示，归档的不出现。开关在资料库页 ··· 菜单、库标签的右键 / 长按、设置 → 任务 → 编辑资料库列表；侧栏里那一项右键能「取消在侧边栏显示」。跟账户同步到各设备。
  - 项目也能放进侧边栏（Rei 2026-10-28「项目和资料库一样，项目也可以显示在侧边栏」）：显示的项目排在「计划 → 项目」下面，用项目自己的图标和名字，点了直接打开那个项目，顺序跟项目页一样，默认都不显示，删掉的不出现（项目没有归档，结束日期过了照常显示）。开关在项目页右上角 ··· 菜单、项目列表里卡片的右键 / 长按；侧栏里那一项右键能「取消在侧边栏显示」。跟账户同步到各设备。
- 资料合并：同一部片记成了两条（「沙丘2」和「Dune: Part Two」）时，可以合成一条：在资料详情 ··· 里选「合并到…」，或者在资料库页多选后点「合并」。资料库页还会提示「可能重复 N 组」（同名，或 IMDb / 豆瓣编号相同），一组一组确认。合并时并排对比，选留下哪条，有冲突的字段各选一个；用到它们的任务都改用留下的那条，合并后能撤销。人物也能这样合并。
- 资料字段 / 任务字段：片名、海报、年份、作者、平台、链接这类属于“这部片本身”，存在资料上；看到第几集、读到第几页、这次买几件属于“这一次”，存在任务上。
- 人物：一个人物列表，每人有头像；任务能关联人物，界面上算人物库的资料，和别的资料放在一起（2026-10-28）。人物也是资料库里的一个库，从资料库页的「人物」标签进（侧栏没有单独的入口，Rei 2026-10-26），⌘K 也能搜到人。
- 第一条资料所在的库决定任务怎么显示；新建任务时挑第一条资料，正文空着就套这个库的正文模板，完成方式没手动选过就用库的默认。
  - 一条资料都没挂：没有标题的 markdown 文本。内置的库有 影视、游戏、书籍、项目、课程、旅行、购物、餐厅、饮食、人物；也能自定义版式、字段、正文模板。项目可以设默认资料库。
  - 资料库编辑器（设置 → 任务 →「资料库」，或资料库页「编辑」）：能新建资料库；能改名字、图标（lucide 或 emoji）、颜色、资料库版式（竖版海报 / 方形 / 横幅 / 圆形）、默认完成方式、正文模板、在选择器里的顺序；字段能增删、改名、排序、隐藏，分资料字段和任务字段。删掉的字段，值还留着，加回同名字段又能看到。
  - 资料库建好后只能改和归档，不能删，内置的和自定义的都一样（Rei 2026-10-17）。归档只是让以后的任务选不到它：它不再出现在选择器（挑资料的面板 / 项目默认资料库）、资料库标签条和资料库编辑器主列表里（编辑器列表最底下「已归档 N 个」里能取消归档）。用过它的旧任务和资料照常显示，字段值也能改；⌘K 照样搜得到它的资料；以它为默认资料库的项目，照样用它新建任务，项目页照常显示（Rei 2026-10-17 纠正：「项目的类型被归档后不退回，搜索里出它的资料。归档只是让它不能被后续任务使用呀」）。

## MVP 功能
0. 我的一天：从搜索或任何视图把任务加进今天的清单（首页）。顶部添加框只有输入框，右边不放「从全部任务添加 ⌘K」（Rei 2026-10-26「删除从全部任务添加的按钮」），从全部任务挑还是按 ⌘K / Ctrl+K。在框里按回车，任务进今天并马上打开，和点一行一样（Rei 2026-10-26「从这里添加任务后立即打开任务」）：宽屏光标留在框里，能接着加，详情跟着换成最新那件；手机整页推入，键盘收起。我的一天、待安排、可做三页的中间列不放页头（Rei 2026-10-26「我的一天、待安排、可做的中间列的header去掉，换成输入框」），最上面就是添加框：待安排和可做加进待安排；原来副标题里的日期、件数挪到添加框下面一行小字，我的一天的「打开小窗」挪到添加框行尾；手机上标题在顶栏。「建议」行尾不放原因徽章（今天到期…），也不放「+ 加入」按钮（Rei 2026-10-25「任何情况下都不显示这两个按钮」）：到期看行里的日期，加入用这一行的右键 / 长按菜单（所有任务列表行都有：查看详情 ｜ 加入 / 移出我的一天）。我的一天列表的行尾也不放 ×（Rei 2026-10-25「删除my day中的条目右侧的x按钮」），移出同样走行菜单，或详情里的太阳。能拖动排序的列表（我的一天、待安排、资料库、字段）拖完不留高亮：不选中被拖的行，不打开详情，鼠标 / 触屏拖完也没有焦点环；键盘拖动保留键盘焦点（Rei 2026-10-25「拖拽调整顺序后不要highlight」）。待安排：还没定哪天做的事都在这里；新建的任务默认进这里，从我的一天新建的才直接进今天
1. 琐事列表（Agenda 式时间线，今天居中）
2. 项目页（Rei 2026-10-26「每个项目的视图支持列表、看板、时间轴，排序支持创建时间、修改时间、开始时间、到期时间，正序、倒序。视图和排序放在右上角图标按钮，点击dropdown。新建任务也统一换成输入框。标题和图标左上角，小一点，和右侧图标对齐」「添加另外一个视图：任务链」「把项目中的任务关系按照任务链排列」）：左上角小一号的图标和名字，右上角「视图」「排序」两个图标按钮，点开是下拉菜单。视图有列表、看板（按状态分四列，拖卡片改状态）、时间轴（开始到到期的横条，日 / 周 / 月，今天线，前后关系画箭头，没日期的在「未定时间」）、任务链（项目里的前后关系按详情「任务链」的排法排成一条条链，链上别的项目的任务也列出来；没有前后关系的在最后「单独的任务」）。排序有默认顺序、创建时间、修改时间、开始时间（任务的日期，日期段的开始日）、到期时间（倒数日是目标日，日期段是结束日，其他是任务的日期），正序 / 倒序，没这个日期的排最后；任务链视图里排序只管链的先后。每个项目记住自己的视图和排序，只记在这台设备上。顶上是添加框，回车加到这个项目并马上打开。
3. 关系图完全去掉了（Rei 2026-10-23 先删了侧边栏的全局关系图页：「侧边栏的Graph选项卡并不是我想要的，可以删掉」；2026-10-26 项目里的也删了：「关系图完全去掉」）。想看前后关系，用项目页的「任务链」视图或详情里的「任务链」
4. 可做清单（所有可开始的任务）

21. 从滴答清单导入（Rei 2026-10-21：「添加从dida365导入任务的功能，在菜单栏的File/Import/Dida365，点击后弹出一个导入窗口」，追加「不能直接连接dida365么」）：桌面 app 菜单栏 文件 → 导入 → 滴答清单（macOS 保留标准的 App / 编辑 / 窗口菜单），设置 → 数据和 ⌘K 里也有「从滴答清单导入…」（桌面 app 设置窗口里点它，导入窗口开在主窗口里）。导入窗口两种方式：「连接滴答清单」（默认，填滴答清单网页版 设置 → 账户 → API Token 生成的令牌，令牌只存在这台设备上，可「忘记令牌」；要先登录 Mindough，请求经 Mindough 的服务器转一下）或「从备份文件导入」（网页版 设置 → 账户与安全 → 生成备份 的 .csv，选择或拖进来）。读完先预览：多少件、未完成 / 已完成 / 已放弃各几件、每个清单几件、会新建哪些项目；可以选导哪些状态（默认都导）、每个清单放进哪个组（新建 / 并入已有 / 不放进项目，收集箱默认不放进项目）。读之前可以选导入哪段时间的任务（全部 / 最近半年 / 最近 30 天，两种方式都有；按任务最后修改或完成的时间算，未完成的也算在内，Rei 2026-10-26）。导入后显示成功几件、跳过几件和原因，可整批撤销。再导一次不会重复（按滴答清单的任务 id 认）。清单 → 项目，文件夹 → 项目的分类，放弃 → 关闭，子任务 → 父任务的「先做完这些」，清单子项 → 待办清单，标签和优先级写成正文末尾的 #标签。字段映射见 docs/IMPORT-DIDA.md

## 不做
多人协作与共享、多层文件夹分类。

- 列表行状态标记（Rei 2026-10-27「整行标题变色的，不要用这种方式，可以用标题下方用不用的图标来标记…hover显示tooltip」）：状态不给标题上色，只在标题下用图标标：🔒+数字=还在等 N 件事、开锁=可开始、播放圈=进行中、禁止=已关闭、地球+偏移=时区、链接+数字=相关任务；鼠标悬停 400ms 显示文字（ui/HoverTip），触屏不弹，文字同时是读屏标签。顺序：类型、组、日期、日期段、时区、重复、相关任务，然后是状态图标，最后是副标题（Rei 2026-10-27「状态可以放在属性后面」）。
- 列表行不显示副标题（Rei 2026-10-27「副标题永远不在列表显示」）：带资料的任务，正文第一行只在详情里看。
- 列表收紧（Rei 2026-10-27）：页面上下左右留白 20px，分组之间 20px，行高 40px、行上下内边距 3px。macOS 无标题栏时，中间列顶部只留 10px 拖动条（红绿灯只在侧边栏，不用给中间列留 38px）。
- 出错不白屏（Rei 2026-10-27「点击了一个任务…页面变空白」）：页面和详情各包一层 ErrorBoundary，渲染出错只换掉那一块，显示出错信息和「再试一次」，换任务或换页面自动重试。
