# Mindough 产品说明

名字来自“满都”（都读 dōu），英文读 /ˈmaɪn.doʊ/。

## 给谁 / 解决什么
给 Rei 自己（登录范围待定）。市面任务工具都靠多层分类管理；Mindough 让任务完成后自然接上后续任务（一个或多个，FS 完成→开始），像前导图 PDM，同时有一条 Agenda 式时间线记琐事。

## 核心概念
- 任务：只有 markdown 正文，没有标题；状态 待办 / 进行中 / 完成 / 取消。
- 依赖：FS，前置全部完成 → 可开始，否则被阻塞；可跨组；不允许成环。
- 组：名称、图标、开始 / 结束时间、分类；装多个任务。
- 分类：名称 + 颜色，挂在组上。
- 任务类型：决定显示方式和新建模板。默认“琐事”纯文字；内置 影视、游戏、书籍、项目、课程、旅行、购物、餐厅；可自定义版式、字段、正文模板；组可设默认类型。

## MVP 功能
1. 琐事列表（Agenda 式时间线，今天居中）
2. 组视图（卡片 + 组内列表 + 组内依赖图）
3. 依赖图（全局 / 按组，拖线连依赖，颜色区分状态）
4. 可做清单（所有可开始的任务）
5. 完成任务时提示解锁了哪些后续，可一键新建后续
6. 快速新建、搜索、按分类筛选
7. 任务类型：内置 8 种 + 自定义（显示变体 + 创建模板）
8. macOS / Windows / iOS / Android / Web，离线可用，多端同步（Google 登录）
