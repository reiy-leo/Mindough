# 类型编辑改版（已按方案 C 实现，2026-10-28）

> Rei 2026-10-28「按方案C执行」。做了什么、和下面写的哪里不一样，见 PLAN.md「类型页改版：方案 C」。下面保留当时给 Rei 审的原文，只在「C 要你定的」后面补了结论。

Rei 2026-10-28：「类型的这个交互方式可以更现代一点么，更改计划让我审核」。
改的是设置 → 任务 → 类型，和侧栏「管理 → 类型」页，两处用的是同一个编辑组件。规则不变：类型能加、能改、能设成不显示，不能删。

## 现在的问题

- 每行一排按钮：颜色圆点、眼睛、上移、下移、箭头，27 行一起看很乱，像后台表格。
- 排顺序只能一格一格点上移、下移，把「观影」挪到最前要点 26 下。
- 图标和颜色分开放：图标是彩色线条，旁边又有一个同色圆点，同一个信息说了两遍。
- 不显示的类型混在列表里，只是眼睛换了图标，扫一眼分不出来。
- 改名字是直接在行里打字，点错一下就进了编辑。

## 方案 A：干净列表 + 拖动排序（推荐）

参考 Things 3、Apple 提醒事项的列表管理。

每行只剩三样：
1. **彩色图标块**：圆角方块，底色是类型颜色，图标白色。颜色圆点去掉。
2. **名字**。
3. **右边**：用了几次（灰色小字，没用过不显示）和 `>`。

其余操作收起来：
- **排顺序**：直接拖。电脑上鼠标移到行上，左边出现拖动把手；手机上长按拖。键盘选中一行后按 ⌥↑ / ⌥↓ 移动。资料库编辑器已经这样做了（react-aria 的 GridList），类型照搬，两边手感一样。
- **改名字、换图标、换颜色**：点一行打开编辑面板（电脑上是行旁边的弹层，手机上是底部面板）：
  - 最上面一行：图标块 + 名字输入框，改完回车或点外面就保存，撞名不改并提示。
  - 颜色：12 个色块一排，点了马上变。
  - 图标：带搜索的图标网格（Lucide），常用的排前面。
  - 最下面：「不显示」开关；类型页里还有「查看用到它的任务和项目」。
- **更多操作**：电脑上悬停出现 `···`，右键也行；手机上左滑。菜单里是：编辑、不显示 / 显示、移到最前、移到最后。
- **不显示的**：从列表里拿出来，放到最底下折叠的「不显示的 N 个」里，点开才看到，名字变灰。拖回上面或点「显示」就回来。
- **新建**：列表最上面一个「+ 新类型」按钮。点了新建一行并直接打开编辑面板；图标和颜色按名字先猜一个（比如「跑步」给跑鞋图标、橙色），不满意再换。
- **找**：超过 12 个时，列表上方出现搜索框，按名字筛。筛选时不能拖。

类型页（侧栏「管理 → 类型」）：宽屏时左边是这个列表，右边是选中类型的详情——上面是图标块和名字（可以直接改），下面是用到它的任务和项目。这时点一行就是打开右边的详情，不弹编辑面板，编辑在右边头部做。

## 方案 B：图标网格

像 iOS「快捷指令」：一屏排满彩色图标块，名字在下面，长按进入「抖动」状态拖着排、点 × 设成不显示。

好处是好看、一眼能看全 27 个。坏处是看不到用了几次，名字长了要截断，电脑上拖着排不如列表顺手，也不好接类型页右边的详情。我不推荐，放这里给你比较。

## 方案 C：搜索优先 + 左右两栏 + 按大类分组（Rei 2026-10-28 说 A、B 都不好之后补的，现在推荐这个）

Rei 的意见：B 类型一多很难快速定位，A 也不好。问题的根子是：A、B 都还在让人「看着一长串手动排顺序、逐个点按钮」。C 换个思路：**先找到，再改；顺序不用手排。**

### 1. 找：顶上一个搜索框，打字就定位

- 打开就光标在搜索框里。输「运」出运动，输「yd」也出运动（拼音首字母），输英文名也行。
- ↑↓ 选，回车打开右边的详情。
- 搜不到时最后一行是「新建“跑步”」，回车就建好并打开。新建不再是单独的按钮和输入框。

### 2. 看：按大类分组，不按手排的顺序

27 个类型分成 5 组，每组一个小标题，可以折叠：

- 身体：健康、运动、作息、冥想、服药、护肤、个人护理、饮食
- 生活：整理、清洁、采购、维护、植物、宠物、理财
- 学习和工作：学习、读书、写作、语言、工作、记录
- 爱好：游戏、玩乐、观影、乐器、创作
- 人：社交

自己加的类型默认进「其他」，在详情里能换组。组只是为了好找，不影响别的地方怎么用类型。

每行只有图标、名字、用了几次，没有按钮。

### 3. 改：右边是详情（宽屏），窄屏整页推进去

点一行（或回车），右边显示这个类型：

- 头部：图标块和名字，名字直接点着改；点图标块弹出图标和颜色（上面 12 个色块，下面带搜索的图标网格）。
- 一行三档开关：**常用 / 普通 / 不显示**。
- 下面列出用到它的任务和项目（就是现在类型页点进去看到的东西）。

### 4. 顺序：用「常用」代替手动排

现在手动排顺序，其实只是为了让选择器第一屏出现想要的那几个。C 去掉上移、下移和拖动，改成：

- 标成「常用」的排在选择器最前面；
- 其余的按最近用过的先后排，最近用过的在前；
- 「不显示」的在选择器里没有，在编辑列表里沉到最底下的「不显示」组，名字变灰。

这样新加一个类型，用几次自然就靠前，不用去排。

### 5. 键盘和手机

- 电脑：⌘F 或直接打字聚焦搜索；在列表里按 ⌘1/⌘2/⌘3 切常用 / 普通 / 不显示；Delete 不做事（类型不能删）。
- 手机：搜索框固定在顶上；左滑一行出「常用」「不显示」两个按钮；点一行整页进详情。

### C 要你定的

1. 用「常用 + 最近用过」代替手动排序，可以吗？还是仍要能拖着排？
2. 上面 5 个大类怎么分你看着改（直接在文档里改名单就行）。
3. 设置 → 任务 → 类型 只放一个「管理类型…」，点了打开侧栏的类型页，两处不再各放一份列表，可以吗？

结论（2026-10-28）：
1. Rei 已定（07:08）：用「常用 + 最近用过」代替手动排序，不能拖着排。
2. 没改，按上面 5 个大类做；自己加的默认「其他」，详情里能换组。
3. Rei 已定（07:08，改了建议）：「去掉设置中的入口」——设置里完全没有类型，连「管理类型…」也不放，类型只在侧栏「管理 → 类型」页管。

## 各方案都会做

- 改动马上保存，不用点「完成」；设成不显示、移到最前这些都能撤销（底部提示条「撤销」）。
- 三套皮肤都按各自系统的样子画：Apple 是分组圆角列表，WinUI 是 ListView，Material 是带分隔的列表。
- 中英文和其余 7 种语言的文案一起补；读屏能读出「运动，用了 2 次，第 6 个」。
