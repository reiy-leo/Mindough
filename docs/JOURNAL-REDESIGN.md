# 日记改版：三个方向（待 Rei 审）

Rei 2026-10-25：「感觉日记的 design 好老旧，有没有更有趣、现代的设计，给我原型简图，让我审核」。

这份文档只出方向和原型简图，没改产品代码，也没部署。我推荐 **方案 B「心情为中心」**，正文排版借方案 C 的大字和留白。理由见第 4 节，第 5 节是要 Rei 回答的问题。

原型图在 Drive「Projects/mindough/07-日记改版原型图」：<https://drive.google.com/drive/folders/1sR0r6_ukLt59DPDBXFrXRLxFovhWR__3>。先看 `overview.png`，三个方案并排。

## 1. 现在为什么显得老旧

对照的是现在的日记页（桌面两张白卡片：左边月历 + 列表，右边日期 + 心情 + 编辑器）。

1. **像在填表，不像在写东西。** 日期标题下面常驻一块 2 × 6 的心情按钮，选中是一个蓝色方框，写完了它还占着正文上面三分之一。整页读起来是「表单 → 输入框」。
2. **月历是日期选择器，不是回顾。** 心情只占日期下面一个 4 像素的小点，一个月过得怎么样看不出来。12 个动画心情是日记最有意思的东西，只在点的那一下露脸。
3. **列表只有「日期 + 第一行 + 字数」。** 没有心情颜色，没有图，翻旧日记没有回看的乐趣。
4. **正文和任务内容长一个样。** 同样的字号、同样的白框、同样的边距，日记没有自己的「纸」。
5. **空状态只有一行灰字。** 今天还没写时，页面不会主动问一句，也没有先选心情的入口；页头的大图标和右下角新建任务的浮动按钮又分走了注意力。

## 2. 三个方案都守的规则

改的是样子，不改 JOURNAL.md 第 0 节的决定：

- 一天一篇；只有心情一个可选字段，12 个动画心情，可以不选，再点一次取消。
- 将来的日子不能写：月历上画成虚线格或空心点，点不了。
- 不做「这一天」汇总；每晚 21:00 提醒照旧；「一天从几点开始」照旧（默认 5 点）。
- 附件照旧（图片缩略图、点开大图）；同步冲突的「另一台设备上同时写的」照旧是折叠块（方案 C 的图里画了）。
- 正文用 Tiptap 能做到的东西：段落、标题、清单、引用、折叠块、选中文字弹出的气泡菜单。
- 桌面是三列布局：侧边栏 | 月历或列表 | 当天的日记。数据表、同步、导出都不动。
- 原型里没画新建任务的浮动按钮，实际照旧保留（要不要在日记页藏起来见第 5 节）。

标了 「可选」 的是新功能建议，不在现有决定里，Rei 点头才做。

## 3. 三个方案

### 方案 A：时间线卡片流 · 封面式

像 Day One 和 Apple 日记 app：一天一张卡，往下刷就是在翻相册。

- **桌面**（`A-1`）：中间一列顶部是这周 7 天的横条（每天下面一个小心情脸），下面按「本周 / 上周」分组的卡片。卡片左边一道心情色竖条，大号日期，两行预览，有图就在右边放缩略图。右边写作区顶部是封面大图（当天第一张图片附件），日期压在图上，心情是右下角一颗胶囊；Tiptap 工具栏浮在底部。
- **手机**（`A-2`）：今天那篇是一张带封面的大卡；选心情从底部弹出面板，4 × 3 宫格，选中的那张脸放大、底色变成心情色。
- **空状态**（`A-2` 第三张、`A-3` Apple 暗色）：列表顶部一张虚线卡「今天还没写」；写作区封面位置是斜纹占位「拖一张照片进来」，下面直接摆 12 张脸和「写几句今天的事…」。

| | |
|---|---|
| 亮点 | 最「现代 app」的样子；有图的日子很好看；卡片和封面一眼认得出哪天 |
| 取舍 | 很依赖照片：大多数日子没图时封面是空的，卡片退回普通列表；月历收成按钮，按月回看要多点一下；卡片阴影和 Things 3 的克制不太搭 |
| 实现成本 | **中**（约 1.5–2 天）：卡片列表、周横条、封面（取第一张图片附件，不加新字段）、底部心情面板 |

### 方案 B：心情为中心 · 情绪月历 + 大字写作

像 Daylio 和 How We Feel：心情是日记唯一的字段，那就让它当主角。

- **桌面**（`B-1`）：中间一列是「情绪月历」，每格铺满当天心情的淡色，中间画那张脸；没写的日子浅灰，将来的日子虚线。月历下面一条「这个月的心情」分布条 「可选」，再下面是几行简短列表。右边写作区顶部按心情色渐变，大号日期「25」，右上角一张 76px 的大脸，点它换心情；正文 20px，行距宽。
- **手机**（`B-2`）：日记首页就是情绪月历，底部一个按钮「今天 · 满足 · 接着写」。选心情是一个半圆「心情轮」：12 张脸从左边「开心一点」排到右边「不太好」，中间放大显示选中的那张并播动画。
- **空状态**（`B-2` 第三张、`B-3` Material 3 暗色）：大字问「今天感觉怎么样？」，下面是心情轮，中间一个虚线圆「点一张脸」；底部「先不选，直接写」。月历上今天那格是虚线加号。

| | |
|---|---|
| 亮点 | 最「有趣」：12 个动画脸从配角变主角；一个月的心情一眼看完，回看有乐趣；没有照片也好看 |
| 取舍 | 颜色多，写作页跟着心情变色可能嫌花（可以只在页头淡淡一层）；心情轮在桌面要配键盘操作（← → 选、回车确认）；分布条是新东西 |
| 实现成本 | **中偏大**（约 2–2.5 天）：情绪月历格子、心情轮（触屏滑动 + 键盘）、每个心情的页头渐变令牌（三皮肤 × 明暗）；分布条再加半天 |

### 方案 C：纸感 · 杂志排版

像 Bear、Stoic 和一本好排版的杂志：把框和卡片都拿掉，只留字。

- **桌面**（`C-1`）：中间一列是「目录」：顶部大字「十月」和一个点阵小月历（一天一个心情色圆点），下面每天一行，大号衬线日期数字 + 两行预览 + 小心情脸，用细线分开。右边是一页暖白色的纸：衬线大标题「十月二十五日」，第一个字下沉，引用变成居中的大字摘句，图片像拍立得一样微微歪着；选中文字弹出 Tiptap 气泡菜单；页脚「— 286 字 —」。
- **手机**（`C-2`）：写作页就是一页纸，底部一条细工具栏。选心情是一条「滑动放大条」：按住左右滑，手指下的脸放大（像 macOS 程序坞），松手就选上。
- **空状态**（`C-2` 第三张、`C-3` WinUI 3 亮色）：横线稿纸 + 闪烁的光标 + 「写几句今天的事…」，下面一行小字「每晚 21:00 提醒写日记」；桌面上点「心情」弹出同样的放大条。

| | |
|---|---|
| 亮点 | 最安静、最像「写东西」；质感最接近 Things 3；改动集中在排版和令牌，成本最低 |
| 取舍 | 「有趣」靠细节，不够跳；衬线中文字体要解决（macOS 有宋体，Windows 没有好看的系统衬线体，要么退回黑体，要么打包字体，多 5–10MB）；心情存在感最弱 |
| 实现成本 | **小到中**（约 1–1.5 天）：纸色和字体令牌、首字下沉、点阵月历、Tiptap 气泡菜单（自带 BubbleMenu）、放大条 |

## 4. 推荐：B 为主，正文借 C

1. Rei 当初只留了心情一个字段，还专门要了 12 个动画图标。B 是唯一把它们放到台前的方案，「有趣」主要来自这里。
2. 情绪月历解决了「回看没意思」：不点开任何一篇，也能看出这个月哪几周累、哪几天开心。
3. B 不靠照片撑场面。A 在没图的日子会退化成普通列表。
4. B 的写作区借 C 的做法：去掉白框，正文 19–20px、宽行距，页头的心情色只留很淡的一层。这样既有颜色也不吵，和 Things 3 的克制不冲突。
5. 成本可控：分布条先不做，心情轮先做触屏和键盘两种操作，大约 2 天。

如果 Rei 想先快速见效，可以先上 C 的排版（1 天），再把 B 的情绪月历和心情轮加进来。

## 5. 要 Rei 回答的问题

1. **选哪个方向？** A / B / C，或者混搭（推荐 B 的月历和心情轮 + C 的正文排版）。
2. **选心情用哪种操作？** 底部宫格面板（A）/ 半圆心情轮（B）/ 滑动放大条（C）。可以和布局分开挑。
3. **要不要「这个月的心情」分布条和「写了 N 天」？**（可选，新功能；JOURNAL J3 本来打算做热力图和连续天数，可以合在一起做。）
4. **写作页跟着心情变色可以吗？** 推荐只在页头一层很淡的渐变，三皮肤都用；嫌花就只用中性色。
5. **日记页要不要藏掉新建任务的浮动按钮？** JOURNAL 第 3 节定的是保留；改版后写作区更像一页纸，浮动按钮会压在正文上。推荐在日记页藏起来，⌘K 照常能新建任务。
